# Dify Integration

OpenFusion exposes an OpenAI-compatible API and can be added to Dify as a custom OpenAI-compatible provider.

Use:

```text
Base URL: http://YOUR_OPENFUSION_HOST:8000/v1
Model: openfusion/parallel-synthesis
```

For local testing, keep OpenFusion on `127.0.0.1`. For server deployment, set an API key and network access controls.
